𝑷𝒓𝒐𝒋𝒆𝒄𝒕 𝑫𝒆𝒔𝒄𝒓𝒊𝒑𝒕𝒊𝒐𝒏 <br>
✩My Python Mini Toolkit is a simple, menu-based program that runs in the terminal. When you run it, a menu is presented to you where you can choose from 3 mini tools I built. Each tool is interactive and takes in your input values. This project was built to show the Python concepts that I have learnt from the Life Choices Academy YouthCode programme.

𝑭𝒆𝒂𝒕𝒖𝒓𝒆𝒔 𝒐𝒇 𝒕𝒉𝒆 𝒑𝒓𝒐𝒋𝒆𝒄𝒕 <br>
✩ What it does ⟶ <br>
1.	Grade Calculator : I ask for your score and tell you your letter grade (A–F)
2.	To-do List : I present you with  a menu of to-do list actions such as checking your taks, adding a new task, removing it and then finally exiting the tool
3.	Daily Motivation Generator : Need some motivation to work, study or just get up in the morning? this tool comes with motivational quotes that helped me, others and hopefully you to get through the day!

𝑷𝒚𝒕𝒉𝒐𝒏 𝑪𝒐𝒏𝒄𝒆𝒑𝒕𝒔 𝑼𝒔𝒆𝒅 <br>
✩Variables & data types ⟶ Throughout the project, I utilized integers, floats, and strings. <br>
✩User input & output ⟶ I utilized input() and print() with f-strings to engage with the user. <br>
✩Type casting ⟶ I applied int() and float() to transform user input into usable numerical values. <br>
✩Comparison operators ⟶ I employed ==, <, >, and >= for verifying the grades. <br>
✩Conditionals ⟶ I utilized if, elif, and else to manage various results in the Grade Calculator and the To-Do List. <br>
✩Functions ⟶ I assigned a specific function to each tool to maintain organization in my code. <br>
✩Modules ⟶ I utilized the built-in random module and developed my own custom module (helpers.py), which I import into (main.py). <br>
